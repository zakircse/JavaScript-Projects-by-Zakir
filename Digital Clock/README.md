# ⏰ Digital Clock

A simple and elegant Digital Clock built with JavaScript that displays the current time in real-time. This project demonstrates dynamic updates using JavaScript and is perfect for beginners learning time-based functions and DOM manipulation.

# 🚀 Features

Real-time clock (hours, minutes, seconds)

12-hour or 24-hour format support

Automatic updates every second

Clean and minimal UI

Responsive design

# 🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

# ⚙️ How It Works
Uses JavaScript Date object to get current time

Extracts:
  Hours
  Minutes
  Seconds
  
Updates the UI every second using setInterval()

Displays time dynamically on the screen

# 💡 Learning Objectives

Working with JavaScript Date object

Using setInterval() for real-time updates

DOM manipulation

Time formatting (12h/24h)
