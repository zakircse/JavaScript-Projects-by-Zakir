# 📅 Mini Calendar

A simple and interactive Mini Calendar built with JavaScript that displays the current date, day, month, and year in a clean and user-friendly interface. Perfect for learning date handling and dynamic UI updates.

# 🚀 Features

Displays current date, day, month, and year

Automatically updates based on system date

Clean and minimal UI design

Lightweight and fast

Responsive layout

# 🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

# ⚙️ How It Works

The app fetches the current date using JavaScript Date object

Extracts:

Day (e.g., Monday)

Date (e.g., 15)

Month (e.g., March)

Year

Displays the information dynamically on the UI

# 💡 Learning Objectives

Working with JavaScript Date object

DOM manipulation

Dynamic content rendering

Basic UI design principles
