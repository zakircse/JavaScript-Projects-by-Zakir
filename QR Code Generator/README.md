# 📱 QR Code Generator

A simple and efficient QR Code Generator built with JavaScript that allows users to instantly create QR codes from text, URLs, or other input data. Designed with a clean UI and fast performance for everyday use.

# 🚀 Features

Generate QR codes instantly

Supports text, URLs, and other input

Responsive and user-friendly interface

Real-time input handling

# 🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

QR Code API(https://goqr.me/api/)

# ⚙️ How It Works
Enter text or a URL into the input field

Click the Generate QR Code button

QR code is generated instantly

Scan the QR code

This project helps to understand:

Event Handling

Working with external libraries/APIs

Dynamic content rendering
