# 👁️ Toggle Password Visibility

A simple and user-friendly Toggle Password Visibility feature built with JavaScript. This project allows users to show or hide their password input by clicking an icon, improving usability and user experience in forms.

# 🚀 Features

Show/Hide password functionality

Toggle using icon (eye / eye-slash)

Smooth and instant interaction

Works with login and signup forms

Lightweight and easy to integrate

# 🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

# ⚙️ How It Works

User enters password in the input field

Click on the eye icon 👁️

Password switches between:

  Hidden (password type)
  
  Visible (text type)
  
Click again to toggle back
